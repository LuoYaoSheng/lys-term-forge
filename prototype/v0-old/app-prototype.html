页面导航（10 页）

后端事实（原型模拟依据）

8 个 Tauri 命令：session_open / session_send / session_close / session_list（后端已注册，前端从未调用） / session_resize / connection_list / connection_save / connection_delete
连接持久化 ~/.termforge/connections.json（0600，密码 AES-256-GCM 加密）：
{ "connections": [ { "id": "conn_a1b2…", "name": "admin@192.168.1.100", "password": "base64(AES-256-GCM…)" } ] }
known_hosts（TOFU + SHA-256 指纹）：首次连接记录，指纹变更时报 MITM 错误（场景「主机密钥变更」）
