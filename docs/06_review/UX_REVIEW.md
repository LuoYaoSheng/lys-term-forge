## 四、修复优先级建议（合并两册 B 类，按用户伤害排序）

> 说明：以下为两册既有分级与 UF 册建议方向的原样合并呈现；最终排期属用户决策（P4 C-1 / PL-01）。

1. **终端运行时错误处理链路**（UF-02 + ST-01，PL-05 规格级表述）——死会话绿点+输入静默丢弃是最恶劣体验（无声无息失效），P4 完全未覆盖。
2. **凭据轮换闭环**（UF-01：编辑连接 F035 + 快照重连指引 B-08）——三重锁死，运维高频诉求在 UI 上无解。
3. **closed 态重连入口 + 断线全局信号**（FL-02/B-05 + FL-11）——能力在、入口漏，修复成本低。
4. **慢连接超时语义**（UF-03/ST-03：超时后对 pending 连接发幂等 session_close，先做取消）——消除状态分裂与孤儿会话。
5. **MITM 专案文案 + 指纹口径勘误**（B-13 + PL-02/UF-04）——最需要用户读懂的错误当前被吞；勘误先行否则确认式 TOFU 数据不兼容。
6. **确认式 TOFU**（B-12/PM-03）——安全决策归还用户；依赖第 5 项勘误。
7. 死文案与语义修正（B-04 Ctrl+R、B-11 新建连接表述）——V1 原型已按修复后规格呈现。
8. 连接中心单一入口卡片化 + 危险确认（B-01/B-06/B-07）——V1 原型已落地并验收。
